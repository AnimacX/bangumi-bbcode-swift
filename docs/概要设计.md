# BBCode 库概要设计

## 1. 项目概述

BBCode 是一个用于解析和渲染 [Bangumi (bgm.tv)](https://bgm.tv) 社区 BBCode 标记语言的 Swift 库。它是纯 SwiftPM 包，支持 iOS 17+、macOS 14+、tvOS 17+、watchOS 10+、visionOS 1+。

主要功能：
- 将 BBCode 字符串解析为 AST（抽象语法树）
- 输出为 HTML 字符串（支持完整 CSS 样式文档）
- 输出为纯文本（去除所有格式标记）
- 使用原生 SwiftUI 组件渲染（`Text`、`View`、`Image` 等）
- 支持 BGM 社区特有功能：Bangumi 贴纸 `(bgmNNN)`、BMO 表情 `(bmoC...)`、`[photo]`、`[subject]`、`[user]`

## 2. 整体架构

库采用**解析-渲染**分离的管道架构：

```
┌─────────────────────────────────────────────────────┐
│                  BBCode String                       │
└─────────────────────┬───────────────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────────────────┐
│            Parser (状态机)                               │
│  ┌──────┐  ┌──────┐  ┌───────────┐  ┌──────┐  ┌───────┐ │
│  │content│→│ tag  │→ │tagClosing │← │ attr │  │smilies│ │
│  └──┬───┘  └──┬───┘  └─────┬─────┘  └───┬──┘  │─────┬─│ │
│     │         │             │            │          │   │
│     └─────────┴─────────────┴────────────┴──────────┘   │
│                   (5 个状态)                             │
│                    ↓ 输出                                │
│              Node Tree (AST)                            │
└─────────────────────┬───────────────────────────────────┘
                      │
          ┌───────────┼───────────┐
          ▼           ▼           ▼
┌──────────┐  ┌──────────┐  ┌──────────┐
│  HTML    │  │  Plain   │  │  Text    │
│  Renderer│  │  Renderer│  │  Renderer│
└────┬─────┘  └────┬─────┘  └────┬─────┘
     │             │             │
     ▼             ▼             ▼
  String        String      TextView enum
                               │
                    ┌──────────┼──────────┐
                    ▼          ▼          ▼
               BBCodeView  BBCodeUIText  BBCodeWeb
               (SwiftUI)   View (iOS)   View (iOS)
```

## 3. 核心模块

### 3.1 Parser 解析器 (`Sources/BBCode/Parser.swift` + `Parsers/`)

**职责：** 将 BBCode 文本字符串解析为 Node 树（AST）。

**状态机 (5 个状态):**

| 状态 | 职责 | 对应文件 |
|------|------|---------|
| `.content` | 扫描纯文本，检测 `[` 进入 tag，检测 `(` 进入 smilies | `ContentParser.swift` |
| `.tag` | 读取开标签名 `[tagname]` 或 `[tagname=attr]`，校验合法性 | `TagParser.swift` |
| `.tagClosing` | 读取闭标签 `[/tagname]`，匹配当前节点 | `TagClosingParser.swift` |
| `.attr` | 读取标签属性值（`=` 到 `]` 之间） | `AttrParser.swift` |
| `.smilies` | 读取 Bangumi 贴纸 `(bgmNNN)` 或 BMO 表情 `(bmoC...)` | `SmiliesParser.swift` |

**核心类型：**
- `Node` — AST 节点，含 `type: BBType`、`value`、`attr`、`children`、`parent`、`paired`
- `Worker` — 驱动解析循环，持有 `currentNode`、`rootNode`、`error`
- `Parser` — 状态机枚举，每个 case 实现 `parse(_:worker:) -> Parser?` 方法

**标签验证机制：**
- `TagManager`: 管理所有标签定义，按名称长度降序排列以优先匹配长名称
- `TagDescription.allowedChildren`: `nil` 表示不允许子标签（如 `[code]`），数组表示白名单
- 解析时检查 `currentNode.description?.allowedChildren.contains(newNode.type)`
- 白名单校验失败时，调用 `restoreNodeToPlain()` 将标签降级为纯文本

### 3.2 Tags 标签系统 (`Sources/BBCode/Tags.swift`)

**职责：** 定义所有支持的 BBCode 标签及其行为规则。

**核心类型：**
- `BBType` — 枚举，定义了 25 个标签类型 + 3 个不支持类型
- `TagInfo` — 标签注册信息：`label`（名称）、`type`（类型）、`desc`（行为描述）
- `TagDescription` — 标签行为：`tagNeeded`、`isSelfClosing`、`allowedChildren`、`allowAttr`、`isBlock`
- `TagManager` — 标签管理器，提供按字符串或类型查询

**标签分类：**
| 分类 | 标签 |
|------|------|
| 结构 | `root`, `plain`, `br`, `paragraphStart`, `paragraphEnd` |
| 布局 | `center`, `left`, `right`, `align` |
| 容器 | `quote`, `code` |
| 链接/媒体 | `url`, `image`, `photo` |
| 文本样式 | `bold`, `italic`, `underline`, `delete`, `color`, `size`, `mask`, `ruby` |
| 列表 | `list`, `listitem` |
| Bangumi 专有 | `bgm`（贴纸）, `bmo`（表情）, `subject`, `user` |
| 不支持 | `background`, `avatar`, `float`（解析时自动剥离） |

### 3.3 Render 渲染器 (`Sources/BBCode/Renders/`)

| 渲染器 | 输出类型 | 公开 API |
|--------|---------|---------|
| HTML (`HTML.swift`) | `String`（HTML 片段或完整文档） | `public func html(_:args:)` |
| Plain (`Plain.swift`) | `String`（纯文本） | `public func plain(_:args:)` |
| Text (`Text.swift`) | `TextView` enum → SwiftUI View | `func text(_:args:)`（internal） |

三种渲染器共享相同的设计模式：
1. 调用 `Worker.parse()` 获取 Node 树
2. 后处理（段落/换行处理）
3. 按 BBType 分发的闭包字典递归渲染子节点

### 3.4 Views 视图层 (`Sources/BBCode/Views/`)

| 视图 | 平台 | 渲染方式 |
|------|------|---------|
| `BBCodeView` | 全平台 | 调用 `BBCode().text()` → 原生 SwiftUI |
| `BBCodeUITextView` | 仅 iOS | HTML → `NSAttributedString` → `UITextView` |
| `BBCodeWebView` | 仅 iOS | HTML → `WKWebView` |

### 3.5 Context 配置系统 (`Sources/BBCode/Context/`)

单例 `BBCodeContext.shared` 提供全局配置：

```swift
BBCodeContext.shared.image.enableContextMenu = true     // 长按上下文菜单
BBCodeContext.shared.image.enableImagePreviewer = true   // 点击图片全屏预览
BBCodeContext.shared.image.enableControlBar = false      // 预览控制条
BBCodeContext.shared.image.delegateImagePreviwer = false // 自定义预览代理
BBCodeContext.shared.mask.enableHovering = false         // macOS 悬停显示遮罩
```

### 3.6 BMO 表情系统 (`Sources/BBCode/Bmo/`)

- `BmoDecoder` — 解码紧凑 BMO 编码（base64url → VarInt → 部件查找）
- `BmoRenderer` — 通过 Core Graphics + Core Image 渲染表情（色调/饱和度/亮度调整、翻转/旋转）
- 部件资源：93 个 PNG 文件（脸/嘴/眼/配件/其他）

### 3.7 Helpers 辅助系统 (`Sources/BBCode/Helpers/`)

| 组件 | 职责 |
|------|------|
| `ImageView` | SDWebImage 异步图片加载 + 保存 + 预览 |
| `ImagePreviewer` | 全屏图片查看器（捏合缩放/拖拽/下滑关闭） |
| `MaskView` | 点击/悬停显示遮罩内容 |
| `RubyView` | 注音标注展示 |
| `Color` | Hex 颜色 + 280+ 网页颜色名解析 |
| `ImageConfiguration` | 注册 SVG/WebP/AVIF 解码器 |
| `OS26Extensions` | 未来系统版本兼容（液态玻璃效果等） |

## 4. 数据流（端到端）

```
用户输入 BBCode 字符串
        │
        ▼
Worker.parse(code)
  ├── 初始化: root Node → content 状态
  ├── 循环: 字符迭代器驱动状态机
  ├── 状态转换: content → tag → (attr | content) | smilies → content
  ├── 标签验证: TagManager 查询 + allowedChildren 校验
  └── 输出: Node 树 (root → children → ...)
        │
        ▼
handleNewlineAndParagraph()  // 换行/段落后处理
        │
        ▼
渲染分发
  ├── htmlRenders[BBType] → String 拼接
  ├── plainRenders[BBType] → 去除格式的 String
  └── textRenders[BBType] → TextView enum
        │
        ▼
视图层封装
  ├── BBCodeView: 直接渲染 TextView → SwiftUI
  ├── BBCodeUITextView: HTML → NSAttributedString → UITextView
  └── BBCodeWebView: HTML → WKWebView
```

## 5. 关键设计决策

1. **状态机而非递归下降：** 使用 5 状态 FSM + 字符级 UnicodeScalar 迭代，避免深层嵌套栈溢出，适合处理任意长度 BBCode。

2. **白名单子标签控制：** 通过 `TagDescription.allowedChildren` 白名单控制标签嵌套，自动将非法嵌套降级为纯文本而非报错，保证容错性。

3. **多渲染后端：** 同一 AST 可输出 HTML、纯文本、原生 SwiftUI 三种格式，满足不同场景（网页导出、搜索索引、原生 UI）。

4. **SDWebImage 集成：** 图片加载使用 SDWebImage 生态，支持 SVG/WebP/AVIF 格式，异步加载 + 缓存。

5. **条件编译隔离平台差异：** iOS 特有视图（`UITextView`/`WKWebView` 方案）通过 `#if os(iOS)` 隔离，macOS 不支持这两个方案。

6. **隐藏内容保护：** `[mask]` 标签渲染为隐藏内容，点击/悬停才显示（通过 `MaskView` 实现），防止剧透。

7. **嵌套 quote 中图片降级：** `[quote]` 内的 `[img]`/`[photo]` 在 Text 渲染中降级为 `[图片]` 占位文本（通过 `inQuote` 参数传递），避免引用嵌套中加载过多图片。
